BOUNDARY RULES (from CLAUDE.md — never break these)
--------------------------------------------------------------------------------

  route.ts        receive req → verify auth → call service → return response
  modules/        all business logic + Prisma queries
  components/     dumb UI — props in, events out, NO fetch
  hooks/          state + client-side calls — pages consume hooks
  services/       client-side fetch wrappers targeting /api/* routes
  lib/            shared server utilities (db, jwt, api-response)

  DO NOT:
    - call fetch() inside a component
    - call fetch() inside a page (use a hook or service + useQuery)
    - write Prisma queries in route.ts
    - accept criadoPorId/tenantId/role from request body
    - skip tenant isolation filters on Prisma queries
    - use any / @ts-ignore
    - add business logic to route.ts
