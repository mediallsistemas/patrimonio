PASSO 3 — Extrair componentes compartilhados
──────────────────────────────────────────────────────────────────────────────
Criar pasta: components/ui/ronda/

3.1  components/ui/ronda/OcorrenciaCard.tsx
     Vem do admin/rondas/page.tsx (componente OcorrenciaCard).

     Exibe: tipo badge, trilogo badge, descrição, patrimônio, foto toggle.

3.2  components/ui/ronda/GrupoAmbientes.tsx
     Vem do admin/rondas/page.tsx (componente GrupoAmbientes).
     Props: { titulo: string; ambientes: RegistroAmbiente[]; variante: 'normal' | 'ocorrencia' }
     Renderiza a lista de ambientes colapsável com cabeçalho colorido.

3.3  components/ui/ronda/FotoLazy.tsx
     Vem do historico/page.tsx (componente FotoLazy).
     Props: { ocorrenciaId: string }
     Usado quando foto não está no payload (view do operador).
     Nota: na view admin a foto já vem inline no OcorrenciaDetalhe.foto —
     o OcorrenciaCard usa diretamente; FotoLazy só é necessário no operador
     se quisermos manter carregamento lazy. Por ora manter o comportamento atual.

3.4  components/ui/ronda/RondaCard.tsx
     Componente unificado que substitui os dois RondaCard locais.

     Props:
       ronda: Ronda
       mostrarTenant?: boolean   (default false — admin mostra, operador não)
       mostrarDono?: boolean     (default false — admin mostra criadoPor.nome)
       agruparAmbientes?: boolean (default false — admin agrupa Ocorrências/Conformidade,
                                   operador lista flat)

     Comportamento:
       - Header: data, badge tenant (se mostrarTenant), badge ocorrências/normal
       - Subtítulo: N ambientes · duração · "por <nome>" (se mostrarDono && criadoPor)
       - Corpo colapsável:
           se agruparAmbientes: renderiza <GrupoAmbientes> (como admin hoje)
           senão: renderiza ambientes individualmente como AmbienteCard
                  (para o operador — mantém detalhes de gases)

     Obs: AmbienteCard (com gases) fica inline em historico/page.tsx por ora
     ou pode ser extraído se atingir 3+ usos. Por enquanto apenas no operador.
